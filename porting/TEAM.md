# Команда (TEAM)

Роли и зоны ответственности. Техлид координирует, собирает результаты, принимает архитектурные
решения и делает рискованные правки; исследовательские и механические задачи делегируются агентам.

| Роль | Исполнитель | Зона ответственности | Результат |
|---|---|---|---|
| Техлид / интеграция | opencode (главная модель) | архитектура, план, code review, git, сборка «воедино» | `PLAN.md`, `JOURNAL.md`, коммиты |
| HW: LILYGO T-2CAN | агент-исследователь | пин-аут T-2CAN, сверка с `gpio_maps`, заземления модулей OVMS | `hw-lilygo-t2can.md` |
| HW: модем A7670E | агент-исследователь | A7670E-LASE vs FASE, драйвер `simcom`, PPP/питание | `hw-a7670e.md` |
| Сервер OVMS | агент-исследователь | протокол V2, регистрация на openvehicles.com, конфиг, приложение | `server-openvehicles.md` |
| Vehicle: Nissan Leaf | агент-исследователь | `vehicle_nissanleaf`, поколение ZE1 (2018), CAN-метрики | `vehicle-nissanleaf-2018.md` |
| Механика | @jeff | поиск/чтение/извлечение фактов, форматирование, тривиальные файлы | по запросу |

## Протокол работы
1. Техлид ставит задачу агенту: цель, обязательные источники (код в репо / веб), формат результата
   (файл в `porting/` + краткий отчёт в ответ).
2. Агент не правит код прошивки без отдельного разрешения — только исследование и документация.
3. Техлид ревьюит отчёт, принимает решение по коду, вносит правки, фиксирует в `JOURNAL.md`.
4. Параллельно запускаются независимые исследовательские потоки.
