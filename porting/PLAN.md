# План разработки (PLAN)

**Цель:** прошивка OVMS Module v3.3 (3.3.006) на базе LILYGO T-2CAN + SIMCOM A7670E-LASE
для Nissan Leaf 2018, работающая с оригинальным сервером https://www.openvehicles.com/
и официальным приложением. Отклонения от upstream — минимальные.

**Определения готовности (DoD) этапов:** см. «Критерии приёмки» у каждой фазы.

---

- [x] Каркас документации `porting/`

**Критерий:** репозиторий содержит весь код и документацию; сборка воспроизводима.

## Фаза 1 — Bring-up железа (ESP32-S3, консоль, CAN)
- [ ] Прошивка и загрузка, консоль через USB-Serial-JTAG
- [ ] Карта GPIO (`gpio_maps/t2can_can.h`) сверена со схемой T-2CAN V1.0
- [ ] CAN1 (TWAI, GPIO6/7) — приём/передача кадров на стендовой шине
- [ ] CAN2 (MCP2515, SPI3, CS=10, INT=8) — инициализация и обмен
- [ ] LED/питание/датчики: что отсутствует относительно Module v3.3 (MAX7317, GPS, SD) — задокументировано

**Критерий:** `can` команды shell работают на обеих шинах.

## Принципы
1. Минимальные отклонения от upstream; правки — только там, где нельзя иначе.
2. Каждое отклонение → запись в `porting/DEVIATIONS.md` (создаётся при первой правке).
3. Каждое действие → запись в `porting/JOURNAL.md`.
4. Исследования агентов → отдельные отчёты в `porting/` до начала правок кода.
